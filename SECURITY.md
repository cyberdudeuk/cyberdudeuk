# Security

This repository holds the GitHub profile page and the script that builds it. The page is static Markdown and images:
it collects no personal data, sets no cookies and runs no code in the reader's browser. Each project has its own
security policy.

To report a vulnerability, use GitHub's private vulnerability reporting: open the **Security** tab of this repository
and select **Report a vulnerability**. Do not open a public issue for a security problem. There is no email route.

Reports are acknowledged within 14 days. Fixes are made in a pull request whose checks must pass, and are recorded in
CHANGELOG.md.
